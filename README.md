# Notes App

A small full stack app to write notes, archive them and sort them with categories.

- `backend/` — REST API (NestJS + TypeORM + PostgreSQL)
- `frontend/` — single page app (React + Vite)

## Requirements

| Tool | Version |
|---|---|
| Node.js | 22.23 |
| npm | 10.9 |
| Docker | 29.1 |
| Docker Compose | 2.40 |

## Features

- [ ] Create, edit and delete notes
- [ ] Archive and unarchive notes
- [ ] List active and archived notes
- [ ] Add and remove categories
